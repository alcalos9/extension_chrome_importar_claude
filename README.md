# Importar Chats a Claude

Sube a tu cuenta de **Claude** lo que guardaste con
[Exportar Chats ChatGPT](https://github.com/alcalos9/extension_chrome_chatgpt) o [Exportar Chats Claude](https://github.com/alcalos9/extension_chrome_claude).

## Instalar (1 minuto)
1. Aquí en GitHub: **Code → Download ZIP**, y descomprime el archivo en una carpeta que no vayas a borrar.
2. En Chrome abre `chrome://extensions` y activa **Modo de desarrollador** (arriba a la derecha).
3. Pulsa **Cargar descomprimida** y elige esa carpeta.
4. Abre claude.ai, inicia sesión y pulsa el icono de la extensión: se abre un panel a la derecha.

## Usar
Elige una pestaña del panel, según lo que quieras importar. En todas: **elige el ZIP tal como lo descargaste** y pulsa el botón azul.

| Pestaña | Qué pasa al importar |
|---|---|
| **Conversaciones** | Eliges dónde dejarla (chat suelto, proyecto existente o nuevo). Se abre un chat en Claude con todo listo: **tú pulsas Enviar**. |
| **Proyectos** | Se crea el proyecto con sus instrucciones y archivos. Luego importas sus conversaciones, que quedan dentro. |
| **Skills** | Se agrega el skill a tu cuenta de Claude. |

Mientras importas una conversación, no cambies de pestaña.

## Si algo no se sube
- **Archivos de una conversación o proyecto:** arrástralos tú desde el ZIP.
- **Un skill:** la extensión descarga su ZIP; súbelo en Claude → Configuración → Capacidades.
- Para quien te ayude, el detalle queda en **Registro**, al final del panel.

## Bueno saber
- **Privado:** todo ocurre en tu computador; no se envía nada a nadie.
- **Si deja de funcionar:** claude.ai puede haber cambiado. Cuéntalo en la pestaña *Issues* de este repositorio.
- Proyecto independiente, sin relación con Anthropic ni OpenAI. Úsalo solo con tus propios datos.
